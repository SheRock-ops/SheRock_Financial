# AI Reflection – SheRock Financial

**Capstone Project:** SheRock Financial – Save Smarter. Grow Stronger.

## 1. How Did You Use AI in This Assignment?

I used ChatGPT as a learning assistant throughout the development of SheRock Financial. AI helped me understand PHP, MySQL, HTML, CSS, and JavaScript, generate example code, troubleshoot errors, and improve my website's design.

I used some AI-generated code as a starting point, then made adjustments to fit my project's requirements and existing structure.

For example, I asked AI to help me develop the Savings Goal Tracker with features for creating, editing, deleting, and contributing to savings goals. I also used AI to improve the design of my Financial Education Hub and make it more interactive.

Some concepts, such as PHP sessions, prepared statements, CSRF protection, and database relationships, were new or challenging for me. I learned more about them by asking follow-up questions, reviewing code examples, and testing how they worked in my application.

## 2. How Did You Understand, Verify, and Adapt the Code?

I did not rely only on AI-generated code. I tested the features in my local XAMPP environment and checked whether they worked as expected.

I used phpMyAdmin to inspect my database and Microsoft Edge Developer Tools to test my website on different screen sizes.

For example, I tested adding contributions to savings goals, managing investment records, and checking the answers and progress in my Financial Education Quiz. When something did not work correctly, I reviewed the problem, asked AI for explanations, made changes, and tested again.

I also improved the website's appearance by adjusting the layout, spacing, and royal blue-and-gold styling. These changes helped make the application more consistent and easier to use.

## 3. What Did You Learn or Get Better At Through This Work?

One of my biggest improvements was understanding how PHP and MySQL work together to create a database-driven web application.

I became more comfortable working with forms, sessions, database queries, and CRUD operations. I also learned more about JavaScript interactivity and responsive design.

What went well was seeing my application gradually come together, especially when the Savings Goal Tracker, Investment Management System, and Financial Education Quiz started working.

What I found challenging was debugging errors, understanding unfamiliar code, and making sure the website worked across different devices.

This project taught me to be more patient, test one feature at a time, and understand the code instead of simply copying it.

**My biggest takeaway:** AI can help me learn and solve problems, but I still need to understand, test, and take responsibility for the code I use.
